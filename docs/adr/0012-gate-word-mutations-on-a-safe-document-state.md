# Gate Word mutations on a safe document state

FormulaBridge 1.0 modifies a document only when it is a supported `.docx` or `.docm` in an ordinary editable state. Track Changes, active real-time coauthoring, read-only or protected state, and a digital signature permit viewing and source recovery but block managed writes with a specific remedy. Unsupported formats remain viewable and must be saved as a new supported-format copy before FormulaBridge management begins.
