# Isolate legacy migration from the core release

Aurora migration is an explicit FormulaBridge 1.x assistant, not an automatic document-open behavior or a FormulaBridge 1.0 dependency. It uses an independently implemented scanner and publicly understood formats, never reuses Aurora executables or resources, always writes a new document plus an audit report, and does not release until representative legacy-document evidence and legal review are complete.
