# Build a vertical product loop before broad features

After the four feasibility spikes, FormulaBridge first delivers one production-shaped vertical loop from signed installation and Ribbon loading through task-pane editing, OMML and local-TeX rendering, atomic Word insertion, save/reopen, and source recovery. FormulaBridge 1.0 expands this loop with its accepted core scope; the detachable editor and chapter-aware numbering target 1.1, while legacy migration and extended interchange remain later 1.x work.
