# Development roadmap

## Milestone 1: core insertion MVP

- Safe LaTeX parser and AST.
- Common OMML structures.
- Inline, display, and numbered insertion.
- Document-local source storage.
- Browser preview and automated tests.

## Milestone 2: editing and numbering

- Reliable selected-formula detection and update.
- Chapter-aware numbering and Word cross-references.
- Formula style profiles.
- Portable per-object metadata for copy/paste.
- End-to-end clean-machine Word tests.

## Milestone 3: legacy support

- VSTO adapter for Word 2016 where Office.js is insufficient.
- Independently implemented legacy object inventory scanner.
- Previewed, non-destructive batch migration with an audit report.
- Embedded SVG/EMF plus PNG fallback for unsupported LaTeX.

## Milestone 4: release readiness

- Accessibility audit and WCAG 2.2 AA work.
- Installer signing, SBOM, privacy policy, and third-party notices.
- Windows 10/11 and Word build compatibility matrix.
- Microsoft Marketplace and centralized deployment packaging.
